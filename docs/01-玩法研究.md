# 01 · 原作玩法研究：《魔幻卡牌》（Spectromancer）

> 用途：整理原作的核心规则与数值区间，作为本项目「复刻玩法」的依据。
> 说明：开发环境网络受限，以下内容来自公开资料（维基百科、Steam 商店页、评测）与类型常识；**标注「待核实」的数值未能逐一对照原作**，仅作量级参考。本项目只沿用规则框架，卡牌名称、效果、数值、美术均为原创。

## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 英文名 | Spectromancer（2008，Apocalypse Studios） |
| 设计 | Richard Garfield（《万智牌》设计者）参与设计；前身为《Astral Masters / Astral Tower》 |
| 类型 | 1v1 回合制卡牌决斗，**无组牌、无抽牌** |
| 职业 | 原版 6 系：牧师、机械师、死灵、混沌、支配、幻术（扩展另有若干），每系对应一种第五元素 |

## 2. 核心规则（已确认）

1. **五种元素资源**：火、水、风、土 + 一种职业专属元素。每种元素独立计数，互不通用。
2. **20 张牌，全部可选**：开局每种元素随机给 4 张，共 20 张。没有牌库、没有抽牌，牌**不会因使用而消耗**——每回合只要对应元素点数够就能打。
3. **每回合每种元素 +1**：点数可以无限积累，攒够了就能打出高费大招。
4. **每回合最多出 1 张牌**（或跳过）。
5. **6 列战场**：双方各一排 6 个格子，生物只能放入己方格子，与对面同列格子相对。
6. **自动攻击**：出牌后，己方生物依次攻击**正对面**的敌方生物；正对面为空则直接攻击敌方英雄。
7. **胜利条件**：将对手英雄生命打到 0。

## 4. 机制要点分析（为什么好玩）

- **完全公开信息**：双方 20 张牌、元素点数全部可见，像下棋一样能预判对手下一步（例如「他火元素 7 点，下回合可能放火雨」）。
- **节奏取舍**：每回合只能出 1 张，「现在放小怪占位」与「攒两回合放大招」是核心决策。
- **位置即一切**：生物只打正对面，阻挡、空位直伤、相邻光环、横扫都依赖站位；高血低攻的「墙」用来封路。
- **元素多样化**：低费元素早期抢位，高费元素后期翻盘；某种元素的增长生物（「每回合额外 +1」）会改变整局节奏。
- **随机性前置**：随机只发生在开局（牌组与元素分布），对局中没有抽牌运气。

## 5. 卡牌效果分类（原作常见类型，本项目全部覆盖）

| 类别 | 示例效果 |
|---|---|
| 召唤触发 | 召唤时对敌方全体/正对面造成伤害 |
| 回合开始触发 | 每回合回血、对随机敌人开炮、成长 |
| 光环 | 相邻己方攻击 +X、己方法术伤害 +X、英雄受伤 -X |
| 资源 | 某元素每回合额外增长 |
| 死亡触发 | 死亡时获得元素 / 对正对面造成伤害 |
| 全局监听 | 任意生物死亡、任意法术施放时触发 |
| 特殊攻击 | 飞行（直击英雄）、横扫（同时打两侧） |
| 法术 | 单体伤害、群体伤害、治疗、消灭、冻结、献祭、召唤衍生物 |
