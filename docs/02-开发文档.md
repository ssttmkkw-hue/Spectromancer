# 02 · 开发文档：《元素决斗》

## 1. 项目定位

- **目标**：在手机浏览器（竖屏）上还原「五元素 · 20 张明牌 · 6 列自动对攻」的决斗玩法，第一阶段与 AI 对战。
- **原则**：规则框架对齐原作；卡牌、职业、美术、命名全部原创。
- **技术**：纯 HTML/CSS/原生 ES Module，零依赖、零构建，任意静态服务器即可运行，便于后续打包为 PWA / 小程序 / App。

## 2. 规则规格（实现即准）

数值集中在 `js/engine.js` 的 `RULES`：

| 参数 | 值 | 说明 |
|---|---|---|
| `HERO_HP` | 60 | 英雄生命，治疗不超过上限 |
| `SLOTS` | 6 | 每方格子数 |
| `BASIC_START_TOTAL` | 12 | 四种基础元素初始总和，每种 1～6 随机 |
| `SPECIAL_START` | 2 | 职业元素初始值 |
| `GROWTH` | 1 | 每回合每种元素增长 |
| `FIRST_TURN_GROWTH` | true | 先手第 1 回合也增长 |
| `SECOND_BONUS` | 2 | 后手额外基础元素点 |

### 2.1 开局
1. 每人按职业生成 20 张牌：5 个元素卡池 × 4 个费用档，每档从 2 张中随机抽 1 张，按费用排序。
2. 随机分配初始元素；随机决定先手，后手获得 `SECOND_BONUS`。

### 2.2 回合流程
```
beginTurn   每种元素 += 1 + 增长加成 → 己方生物「回合开始」效果（左→右）
play        出 0 或 1 张牌：扣费 → 召唤 / 施放 → 「任意法术」监听 → 死亡结算
attack      己方生物左→右攻击：正对面有敌方生物则打它，否则打英雄
endTurn     交换行动方
```
- **可攻击条件**：基础攻击 > 0，当前攻击 > 0，且不是本回合召唤（迅捷除外）。
- **冻结**：生物轮到攻击时若被冻结，则消耗 1 层冻结并跳过本次攻击。
- **伤害结算**：`实际伤害 = max(0, 伤害 − 减伤)`；英雄伤害同理减去己方「守护」光环。
- **死亡结算**：每个动作后统一清理生命 ≤ 0 的生物 → 触发其「死亡时」→ 触发全场「任意生物死亡」监听；循环直至稳定（连锁上限 20 次）。
- **胜负**：任一英雄生命 ≤ 0 立即结束；双方同时归零为平局。

## 3. 卡牌设计

- 4 基础元素 × 8 张 + 4 职业 × 8 张 = **64 张**，另有 2 个衍生物。完整列表见 `03-卡牌数据表.md`（自动生成）。
- 费用档：基础元素 1～2 / 4～5 / 6～8 / 10～12；职业元素（起点 2）1～2 / 3～4 / 5～6 / 8～9。
- 身材公式（参考）：攻 ≈ 费用 − 0～1，血 ≈ 3×费用 + 4～6；带强效果的生物减身材。
- 元素定位：

| 元素 | 定位 | 代表卡 |
|---|---|---|
| 🔥 火 | 直伤、清场 | 烈焰之墙、火雨、陨星坠落 |
| 💧 水 | 冻结、资源、治疗 | 潮汐侍僧、海妖女巫、深渊海皇 |
| 🌪 风 | 迅捷、飞行、打脸、法强 | 雷鹰、风暴使者、风暴之怒 |
| 🪨 土 | 厚血、回复、对称清场 | 山岳巨人、大地震、盖亚化身 |
| ✨ 星辉祭司 | 英雄续航、单体移除 | 守护天使、最终审判 |
| 💀 暗影术士 | 死亡收益、献祭打脸 | 墓穴守望者、死亡契约、亡者军团 |
| ⚙ 机巧师 | 炮塔、减伤、资源 | 加农炮塔、钢铁魔像、超频 |
| 🐺 兽王 | 光环、额外攻击 | 头狼、兽群奔袭、万兽之王 |

### 3.1 卡牌效果钩子

卡牌是 `js/cards.js` 中的数据对象，效果以钩子函数描述，引擎在对应时机调用：

| 字段 | 时机 / 含义 |
|---|---|
| `onSummon(g, c)` | 召唤后 |
| `onTurnStart(g, c)` | 拥有者回合开始 |
| `onAttack(g, c)` | 攻击后 |
| `onDamaged(g, c, n)` | 受伤后仍存活 |
| `onDeath(g, c)` | 死亡时 |
| `onAnyDeath(g, c, dead)` | 场上任意生物死亡 |
| `onAnySpell(g, c, p)` | 任意一方施放法术后 |
| `attack(g, c)` | 自定义攻击（飞行、横扫） |
| `cast(g, p, target)` | 法术效果；`target` 字段：`none / enemyCreature / ownCreature / anyCreature / ownEmptySlot` |
| 静态：`haste reduce growth spellPower auraAdj auraAll heroShield` | 迅捷、减伤、元素增长、法术强化、相邻光环、全体光环、英雄护盾 |

引擎 API（`g.*`）：`damage / damageHero / heal / healHero / freeze / kill / summon / addMana / doAttack / creatureAt / creatures / neighbors / atkOf / spell / rand`。

## 4. 技术架构

```
index.html          页面骨架（菜单 / 对局 / 底部弹层）
css/style.css       竖屏布局、主题变量、动画
js/cards.js         卡牌与职业数据（纯数据 + 钩子）
js/engine.js        规则引擎（无 DOM，可在 Node 运行）
js/ai.js            AI
js/ui.js            渲染、输入、动画、回合驱动
tests/sim.mjs       AI 自对战模拟：稳定性 + 平衡统计
tools/gen-card-doc.mjs  生成卡牌数据表
```

- **状态**：`Game.s` 为纯 JSON（玩家、元素、手牌 id、棋盘生物实例、随机种子、日志），可 `clone()`、可序列化存档/联机同步。
- **随机**：引擎内置可复现的种子随机数（mulberry32），同种子同操作 → 同结果，便于回放与联机校验。
- **事件**：引擎每个原语都会 `emit` 事件（attack/dmg/heal/hero/freeze/death/summon/mana/cast），UI 每一步取出事件播放动画后再重绘。攻击阶段按格子逐步执行，因此动画天然有先后。

### 4.1 AI
- 枚举全部合法动作（含跳过），在克隆局面上推演「出牌 + 攻击阶段」，用评估函数打分：
  英雄血量差（低血量时权重升高）＋ 生物价值（攻×2.2 + 血×0.55 + 持续效果加成）＋ 无阻挡威胁 ＋ 少量保留元素价值。
- 难度：新手＝评分加随机扰动；普通＝1 层贪心；困难＝取前 8 个候选，再推演对手最佳回应（2 层）。

### 4.2 平衡验证
`npm test`（`node tests/sim.mjs 200`）进行 AI 自对战。当前数据（400 局，普通 AI）：

| 指标 | 结果 |
|---|---|
| 平均对局长度 | 约 29 个回合（每人约 15 回合） |
| 先手胜率 | 52% |
| 各职业胜率 | 48%～52% |
| 未被使用的卡 | 无 |

调参经历：先手第 1 回合不增长 → 先手胜率 31%；无补偿 → 67%；后手 +2 基础元素 → 52%（采用）。

## 5. UI / 交互设计（手机竖屏）

```
┌───────────────────────────┐
│ 敌方英雄：头像 名字 血条 ☰  │
│ 敌方 5 种元素（点数 +增长）  │
│ [ ][ ][ ][ ][ ][ ]  敌方战场 │
│ ───── 回合提示 ─────        │
│ [ ][ ][ ][ ][ ][ ]  己方战场 │
│ 己方英雄：头像 名字 血条     │
│ ┌ 选中卡说明 / [施放] ────┐ │
│ │ 🔥 💧 🌪 🪨 ✨ 元素页签   │ │
│ │ [牌][牌][牌][牌]          │ │
│ └─────────────────────────┘ │
│ [战报] [对手牌] [跳过出牌▶]  │
└───────────────────────────┘
```
- **单手可达**：所有操作在屏幕下半部分；战场格子宽度按屏宽 1/6 自适应，高度上限 11.5dvh，兼容 iPhone SE 到大屏机型。
- **元素页签**：20 张牌按元素分 5 页，每页 4 张；页签直接显示该元素当前点数与每回合增长，有可出牌的页签有高亮下划线。
- **出牌**：点牌 → 上方显示完整说明并高亮合法目标 → 点目标出牌；无目标法术显示「施放」按钮；再点一次取消。元素不足的牌变灰，点击仍可看说明。
- **信息透明**：点场上生物看实时攻防与状态；「对手牌」弹层展示对方全部 20 张牌（够费的亮显）。
- **状态标记**：💤 召唤失调、❄ 冻结、🛡 不攻击；攻击力被光环提升时显示金色，受伤时血量变红。
- **反馈**：攻击前冲、受击抖动、伤害/治疗飘字、死亡淡出、召唤弹出、英雄受伤震动、对手出牌横幅。菜单可切换快速动画。
- **适配**：`viewport-fit=cover` + 安全区内边距；`dvh` 单位处理移动浏览器地址栏；桌面端居中限宽 480px。
